# Portfolio · David Escalante

Personal portfolio of a full-stack software engineer, built with Next.js (App Router) and exported as a static site.

**Live:** [dav-es.netlify.app](https://dav-es.netlify.app)

## Pages

- **Home:** introduction, photo and key stats
- **Services:** what I build
- **Resume:** experience, education and skills
- **Work:** project carousel with descriptions, links and tech used
- **Contact:** how to reach me

## Highlights

- Page and stair transitions with Framer Motion
- Project carousel with Swiper and animated counters
- Accessible UI primitives (Radix UI, shadcn/ui style) styled with Tailwind CSS and Sass
- Responsive layout and Open Graph image for link previews
- Static export (`output: "export"`), deployed on Netlify

## Tech

Next.js · React · Tailwind CSS · Sass · Framer Motion · Radix UI · Swiper · Lucide / React Icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build   # static site in out/
```
